# AdiZen-Cyber-Toolkit-V1.0
> ⚡ Modular Python toolkit for cybersecurity auditing, automation, and inspection — lightweight, tested, and CI/CD ready.
AdiZen Cyber Toolkit V1.0 — A modular collection of Python-based cybersecurity utilities for auditing, inspection, and automation. Includes lightweight tools for scanning, hashing, filtering, password strength testing, file inspection, and more, with full unit test coverage and CI/CD integration.
